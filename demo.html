JetFood (demo host)

This simulates a customer site with the JetChat widget embedded via one script tag.

Order online

This is a sample host page. The chat widget is loaded exactly the way a real customer site would load it — a single <script src="/embed.js"> at the bottom, which drops an <iframe src="/chat"> in the bottom-right corner and never blocks clicks on the page.

How to test

  • Click the chat bubble (bottom-right) → the panel opens without covering the page.
  • Open the admin at /admin in another tab → this visitor shows up on Live Visitors.
  • From Live Visitors you can Start chat (proactive) — the widget pops open here.
